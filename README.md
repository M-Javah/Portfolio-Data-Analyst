# Portfolio-Data-Analyst
Portfolio de projets en analyse de données – Python, SQL, Power BI, Machine Learning
# Présentation
Onze projets réalisés au cours d’une formation en analyse de données, couvrant Python, SQL, Power BI, dbt, analyses statistiques et apprentissage automatique.
## Projets

### Projet 02 — Comprendre l’évolution des ventes e-commerce

**Besoin métier.** Analyser l’effet des changements de gamme sur les ventes et les comportements de visite.

**Démarche.** Suivi du chiffre d’affaires par catégorie, des visites, des achats, de la conversion et du temps passé.

**Résultat.** Après l’introduction de l’alimentaire, les visites et les achats progressent, mais pas au même rythme.

**Outils.** Excel · tableaux de bord · reporting

**Livrables.** Rapport mensuel (7 pages) et classeur clients affiliés.

### Projet 03 — Interroger une base d’assurance avec SQL

**Besoin métier.** Organiser les données d’environ 30 335 contrats d’assurance et répondre à des questions opérationnelles.

**Démarche.** Dictionnaire des données, schéma relationnel, chargement des tables et requêtes SQL.

**Résultat.** 12 requêtes documentées : contrats, surfaces, cotisations, répartition géographique.

**Outils.** SQL · MySQL Workbench · modélisation relationnelle

**Livrables.** Documentation technique, requêtes et méthodologie (PDF).

**Accès :** [ajouter le lien vers le dossier du projet 03]

### Projet 04 — Analyser la sous-nutrition dans le monde

**Besoin métier.** Explorer la disponibilité alimentaire, la sous-nutrition et l’aide alimentaire à l’échelle mondiale.

**Démarche.** Jointures et analyses Python de quatre jeux de données : population, aide, disponibilité, sous-nutrition.

**Résultat.** En 2017, environ 535,7 millions de personnes sont identifiées comme sous-alimentées dans l’analyse.

**Outils.** Python · Pandas · visualisation

**Livrables.** Notebook et présentation de l’étude.

**Accès :** [ajouter le lien vers le dossier du projet 04]

### Projet 05 — Structurer une base de données immobilière

**Besoin métier.** Consolider des données foncières et géographiques pour analyser les transactions immobilières.

**Outils.** SQL · modèle relationnel · RGPD

**Accès :** [ajouter le lien vers le dossier du projet 05]

### Projet 06 — Fiabiliser les analyses de ventes et de stocks

**Besoin métier.** Rapprocher trois sources e-commerce et ERP afin de fiabiliser le suivi commercial.

### Projet 11 — Identifier des marchés d’exportation attractifs

**Besoin métier.** Aider une entreprise française de volaille bio à cibler ses études de marché internationales.

**Démarche.** 9 variables sur 162 pays ; ACP, CAH et K-means ; caractérisation des groupes.

**Résultat.** Quatre composantes de l’ACP conservent 79,7 % de l’information ; marchés à approfondir proposés.

**Outils.** Python · ACP · CAH · K-means

**Livrables.** Deux notebooks et présentation (21 diapositives).

**Accès :** [Voir notebook et présentation](https://github.com/M-Javah/Portfolio-Data-Analyst/tree/d9513c7996458b07282bf77437ef0a7f099277c3/11-Identifier%20des%20march%C3%A9s%20d%E2%80%99exportation%20attractifs)

### Projet 12 — Prédire l’authenticité de billets de banque

**Besoin métier.** Détecter les billets potentiellement contrefaits à partir de six mesures géométriques.

**Démarche.** Préparation train/test stratifiée, imputations, comparaison logistique, K-means, KNN et Random Forest.

**Résultat.** Régression logistique retenue ; précision annoncée de 99 % et rappel de 98 % sur le test.

**Outils.** Python · scikit-learn · classification

**Livrables.** Notebook, présentation et script de prédiction CLI.
